# 📚 Library Management System

A simple and user-friendly **Library Management System** designed by `Django` `CSS` `SQLite3` to manage books and authors efficiently. The project provides a clean interface for viewing, adding, and managing library records. 📖✨

---

## ✨ Features

* 📚 **Book List** — View all available books
* 📖 **Book Details** — View complete information about a book
* ➕ **Add Book** — Add new books to the library
* ✍️ **Author List** — View and manage authors
